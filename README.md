# ❤️ 3D Heart Visualization & ECG Arrhythmia Detection

An AI-powered healthcare application that combines **Deep Learning** with **Interactive 3D Heart Visualization** to detect and classify ECG arrhythmias. The system enables users to upload ECG data, predict heart rhythm abnormalities, and visualize the affected region on a 3D heart model for better diagnosis and understanding.

---

## 🚀 Project Overview

This project is designed to improve cardiac diagnosis by integrating deep learning-based ECG analysis with an interactive 3D heart visualization. The system processes ECG signals, predicts arrhythmia types using a trained neural network model, and displays the heart in an interactive 3D environment to enhance medical interpretation.

---

- ❤️ ECG Arrhythmia Detection using Deep Learning

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Deepthisirikonda/3D-Heart-Visualization-ECG-Arrhythmia-Detection.git
```

### Navigate to the project folder

```bash
cd 3D-Heart-Visualization-ECG-Arrhythmia-Detection
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the server

```bash
python manage.py runserver
```

### Open in Browser

```
http://127.0.0.1:8000/
```
